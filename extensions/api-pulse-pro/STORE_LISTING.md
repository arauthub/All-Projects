## Title
API Pulse Pro: Network Inspector, Replay & Mock Studio

## Short Description (max 132 chars)
Real-time API & POST request inspector, in-browser request replayer, response mocking studio, cURL exporter & TypeScript generator.

---

## Detailed Description

Stop digging through cluttered DevTools tabs filled with hundreds of static images, font files, and script bundles. 

**API Pulse Pro** is the ultimate developer tool that turns your browser into an IDE-grade API workbench. Designed by engineers for engineers, it gives you immediate clarity and complete interactive control over every single HTTP request and response occurring on any web page.

---

### 🔥 KEY FEATURES

#### 1. Real-Time API & POST Inspection
* Automatically tracks all `fetch()` and `XMLHttpRequest` calls in the page context.
* Dedicated focus on **POST**, **PUT**, **PATCH**, **DELETE**, **GET**, and **GraphQL** calls.
* Color-coded method badges, HTTP status codes, latency waterfall (ms), payload sizes, and exact timestamps.
* Syntax-highlighted JSON viewer for both Request Payloads and Response Bodies.

#### 2. In-Page Floating HUD (Heads-Up Display)
* A sleek, dark-mode glassmorphic floating capsule docked directly in the web page.
* Shows live counters: e.g. `12 APIs | 4 POST | 0 ERR`.
* Flashes an animated pulse dot on every new request.
* Click to open an instant In-Page Quick Drawer without opening DevTools!
* Completely draggable anywhere on screen; toggle anytime with **Alt+Shift+P**.

#### 3. In-Browser Request Replayer
* Ever wanted to tweak a POST body or headers and re-send it with the user's active session cookies and CORS credentials?
* Pre-populate any captured request with one click.
* Replay directly inside the page's execution context or via direct fetch.
* View live results side-by-side with original responses.

#### 4. In-Browser Mock Engine (Response Stubbing)
* Intercept matching API endpoints in the browser and return synthetic responses without touching the server!
* Match endpoints with wildcards (`/api/v1/orders*`) or regular expressions.
* Configure custom HTTP status codes (200, 400, 404, 500), simulated latency sliders (0ms to 3000ms), and custom JSON bodies.
* Test loading spinners, empty states, and error toasts with ease!

#### 5. Auto-Generated TypeScript Interfaces
* 1-click generation of production-ready TypeScript types from request payloads and response bodies.
* Accurately types nested objects, arrays, and primitive values.

#### 6. Multi-Language Code Generators
* Instantly copy any request as:
  * cURL (bash)
  * JavaScript `fetch()`
  * Axios (JS/TS)
  * Python `requests`
  * Go `net/http`

#### 7. Security & Secrets Scanner + JWT Decoder
* Highlights exposed Authorization headers, Bearer tokens, and API keys.
* Built-in JWT Decoder displays decoded Header, Payload claims, and expiration timers.

#### 8. Side-by-Side JSON Diff Tool
* Compare two captured responses or before/after mutations with side-by-side visual diffing.

#### 9. Full DevTools & Studio Modes
* Access via toolbar popup, in-page floating HUD, full-screen studio workbench (**Alt+Shift+S**), or Chrome DevTools panel (**F12**).
