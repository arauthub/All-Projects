## 2. Description of Service
Anti-Gravity Web is an open-source, client-side Chrome Extension designed to gamify web browsing by simulating 2D rigid body physics (zero-G drift, directional gravity inversion, asteroids blasting, and katamari rolling) over webpage elements on active tabs.
