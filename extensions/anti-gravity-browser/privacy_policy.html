Privacy Policy — Anti-Gravity Web

Effective Date: September 18, 2026 • Developer: Abhijeet Raut • Version 1.0.0

1. Overview

Anti-Gravity Web ("we", "our", or "the Extension") respects your privacy. We do not collect, store, sell, or transmit any personal data, browsing history, or user activity. All physics simulations, DOM interactions, and sound synthesis run 100% locally in your browser's memory.

2. Data Collection and Usage

A. Personal Identifiable Information

The Extension does not collect personal identifiers like names, emails, IPs, account credentials, or financial data.

B. Webpage Content & In-Memory DOM Extraction

When activated on an active browser tab, the extension inspects visible DOM elements (headings, cards, buttons) to construct a temporary physics sandbox. This processing is executed purely inside client-side RAM. No webpage text, images, or DOM structure is ever transmitted outside your device.

C. Local Settings Storage

We use Chrome's standard chrome.storage.local API exclusively to save local preferences on your machine (e.g. sound mute toggle, preferred game mode, and tutorial seen state). This data never leaves your computer.

3. Permissions Justification

Permission Purpose
activeTab Permits physics simulation only on the specific tab you explicitly trigger.
storage Persists local audio, difficulty, and tutorial preferences.
scripting Injects the locally bundled Matter.js physics engine when activated.

4. Third-Party Code & Security

Anti-Gravity Web strictly adheres to Chrome Extension Manifest V3 standards: zero remote code execution, zero external analytics, and zero tracking pixels.

If you have any questions regarding this policy, please open an issue at: github.com/arauthub/anti-gravity-browser.
