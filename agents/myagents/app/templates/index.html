🚀 1-Click Google Cloud Run Deployment

You can deploy this entire multi-agent orchestration application directly to Google Cloud Run with a single turnkey script. It automatically configures production container settings, sets up TLS endpoints, and scales from zero to 1,000 instances.

Run in terminal:
cd agents/myagents
./deploy/deploy_to_gcp.sh
What the script automates:
  • Validates Google Cloud SDK (gcloud) authentication.
  • Builds production multi-stage Docker container via Google Cloud Build.
  • Deploys container to Google Cloud Run with 512MB RAM, 1 vCPU, and HTTPS endpoint.
  • Replaces demo configuration with production environment variables.
